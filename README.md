# Zapretiks 0.1

Zapretiks — приложение для Windows с двумя задачами. На «Обзоре» можно запустить, остановить или сменить стратегию zapret из распакованной сборки Flowseal. В «Моих решениях» можно собрать адреса игр и сервисов, проверить изменения и применить их к спискам Flowseal.

## Запуск

Для сборки нужен .NET 10 SDK на Windows. Для запуска собранного приложения нужен .NET 10 Desktop Runtime. Откройте `Zapretiks.slnx` в Visual Studio с поддержкой .NET 10 или выполните в PowerShell:

```powershell
dotnet restore Zapretiks.slnx
dotnet build Zapretiks.slnx -c Release --no-restore
dotnet run --project Zapretiks.App -c Release --no-build
```

Для запуска через Проводник откройте `Zapretiks.App.exe` из `Zapretiks.App/bin/Release/net10.0-windows`. Для переноса на другой компьютер скопируйте всю папку сборки.

Колесо мыши переключает разделы над боковым меню и над страницей без вертикальной прокрутки. Длинные списки, поля и раскрывающиеся меню сохраняют собственную обработку колеса. Навигация останавливается на первом и последнем разделах.

## Сценарий для защиты

1. Нажмите «Посмотреть пример». Выберите карточку учебного решения, откройте описание и сохраните решение в библиотеку.
2. В «Моих решениях» создайте «Учебный сервер» с адресом `https://notes.example.test/demo`. По желанию прикрепите обложку в PNG или JPEG. После сохранения в решении останется `notes.example.test`. Нажмите «Выбрать для установки».
3. Подключите отдельную распакованную копию Flowseal и выберите `general.bat`. Откройте «Проверка изменений». Нажмите «Применить изменения» и откройте `lists/list-general-user.txt`. Адрес появится в блоке Zapretiks.
4. Нажмите «Отменить последнюю запись», чтобы восстановить исходное состояние файлов. Выбранные в библиотеке решения сохраняются. Чтобы убрать адреса конкретного решения, снимите его выбор и примените новый расчёт.
5. Для демонстрации запуска откройте Zapretiks от имени администратора. На «Обзоре» запустите выбранную стратегию, выберите другую и нажмите «Сменить стратегию». Остановите её кнопкой «Остановить zapret». Используйте доверенную сборку Flowseal. [Официальная сборка](https://github.com/Flowseal/zapret-discord-youtube/releases)

## Возможности версии 0.1

| Раздел | Что доступно |
| --- | --- |
| Каталог | Сетка карточек встроенных учебных решений, полное описание по нажатию, поиск по названию, описанию, домену или IP и фильтр по категории. |
| Мои решения | Создание и редактирование решений с необязательной обложкой, выбор для установки, удаление, импорт и экспорт JSON. Обложка передаётся вместе с файлом решения. |
| Стратегии | Поиск `general*.bat`, запуск, остановка, переключение и перезапуск стратегии, включённой из Zapretiks. Запуск из Flowseal отдельно виден в статусе. |
| Изменения списков | Предпросмотр добавлений и удалений, запись с резервной копией, отмена последней записи. Ручные записи и адреса, нужные другим выбранным решениям, сохраняются. |
| Игры | Чтение локальных манифестов из основной и дополнительных библиотек Steam. |

Библиотека, настройки, резервные копии списков и журнал ошибок хранятся в `%LOCALAPPDATA%\Zapretiks`. При закрытии Zapretiks запущенная им стратегия завершается. Чтобы загрузить применённые списки, нажмите «Перезапустить zapret» на «Обзоре». Запущенную извне стратегию перезапустите там, где её включали. [Дорожная карта](ROADMAP.md)

## Проверки

```powershell
dotnet run --project Zapretiks.Tests -c Release
```

Набор проверок запускается без внешнего тестового пакета и возвращает ненулевой код при ошибке. В тестах управления стратегиями используется безвредный процесс, а изменения списков выполняются во временных папках.

Оригинальная сборка принадлежит Flowseal, исходный zapret разработан bol-van. Компоненты Flowseal и WinDivert распространяются отдельно на условиях их лицензий.
