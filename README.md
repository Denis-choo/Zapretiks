# Zapretiks 0.1

Zapretiks — приложение для Windows, в котором можно собрать адреса игры или сервиса в профиль и посмотреть, что он добавит в списки zapret. Познакомиться с примерами или создать свой профиль можно сразу. Для сравнения с файлами нужна распакованная сборка Flowseal.

## Запуск

Для сборки нужен .NET 10 SDK на Windows. Для запуска собранного приложения нужен .NET 10 Desktop Runtime. Откройте `Zapretiks.slnx` в Visual Studio с поддержкой .NET 10 или выполните в PowerShell:

```powershell
dotnet restore Zapretiks.slnx
dotnet build Zapretiks.slnx -c Release --no-restore
dotnet run --project Zapretiks.App -c Release --no-build
```

Для запуска через Проводник откройте `Zapretiks.App.exe` из `Zapretiks.App/bin/Release/net10.0-windows`. Для переноса на другой компьютер скопируйте всю папку сборки.

Колесо мыши переключает разделы над боковым меню и над страницей без вертикальной прокрутки. Длинные списки, поля и раскрывающиеся меню сохраняют собственную обработку колеса. Навигация останавливается на первом и последнем разделах.

## Сценарий для защиты

1. На первом запуске нажмите «Посмотреть пример». Каталог откроет встроенный профиль. Нажмите «Добавить в профили», затем «Открыть профиль».
2. В разделе «Мои профили» создайте профиль «Учебный сервер». Введите `https://notes.example.test/demo` и сохраните. В профиле останется адрес `notes.example.test`. Включите свой профиль в расчёт. Встроенные примеры служат для знакомства с форматом.
3. На «Обзоре» нажмите «Выбрать папку» и укажите распакованную сборку Flowseal. Выберите стратегию, которая использует `list-general-user.txt`, и нажмите «Посмотреть изменения». Если такого домена ещё нет в списке и он не исключён, расчёт предложит его добавить.
4. Кнопка «Обновить статус» проверяет, запущен ли zapret из выбранной папки. После перезапуска приложения профиль и выбранная стратегия сохраняются.

## Возможности версии 0.1

| Раздел | Что доступно |
| --- | --- |
| Интерфейс | Обзор состояния подключения, боковая навигация, список и детали профиля в соседних панелях, анимация переходов. |
| Каталог | Поиск по названию, описанию, домену или IP и выбор категории. Технические сведения раскрываются по запросу. Из примера можно перейти к его сохранённой копии. |
| Мои профили | Создание и редактирование собственных профилей, включение, удаление, импорт и экспорт JSON. Редактор и импорт используют общую проверку доменов, IP-адресов, подсетей и имён стратегий. Новые профили сохраняются выключенными. |
| Интеграция | Проверка структуры папки, поиск `general*.bat`, выбор стратегии, чтение версии. Приложение сверяет путь запущенного `winws.exe` с подключённой папкой при старте, её подключении и ручной проверке. |
| Предпросмотр | Новые записи и количество существующих показаны отдельно по каждому файлу. Есть предупреждения об исключениях и совместимости. Текст отчёта можно скопировать. |
| Игры | Чтение локальных манифестов из основной и дополнительных библиотек Steam. |

Библиотека, настройки и журнал ошибок хранятся в `%LOCALAPPDATA%\Zapretiks`. Состояние процесса относится ко времени последней проверки. Если Windows ограничивает доступ к процессу, приложение показывает неопределённый статус. Запуск, остановка, применение списков с резервной копией и откат запланированы. [Дорожная карта](ROADMAP.md)

## Проверки

```powershell
dotnet run --project Zapretiks.Tests -c Release
```

Набор проверок запускается без внешнего тестового пакета и возвращает ненулевой код при ошибке. Для создания примера JSON экспортируйте один из демонстрационных профилей в приложении.

Оригинальная сборка принадлежит Flowseal, исходный zapret разработан bol-van. Компоненты Flowseal и WinDivert распространяются отдельно на условиях их лицензий.
