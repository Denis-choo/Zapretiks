# Zapretiks 0.1

Zapretiks — приложение Windows для работы с локальными профилями и проверки распакованной сборки Flowseal. Каталог и библиотека доступны с первого запуска.

## Запуск

Для сборки нужен .NET 10 SDK на Windows. Для запуска собранного приложения нужен .NET 10 Desktop Runtime. Откройте `Zapretiks.slnx` в Visual Studio с поддержкой .NET 10 или выполните в PowerShell:

```powershell
dotnet restore Zapretiks.slnx
dotnet build Zapretiks.slnx -c Release --no-restore
dotnet run --project Zapretiks.App -c Release --no-build
```

Для запуска через Проводник откройте `Zapretiks.App.exe` из `Zapretiks.App/bin/Release/net10.0-windows`. Для переноса на другой компьютер скопируйте всю папку сборки.

Колесо мыши переключает разделы над боковым меню и над страницей без вертикальной прокрутки. Длинные списки, поля и раскрывающиеся меню сохраняют собственную обработку колеса. Навигация останавливается на первом и последнем разделах.

## Сценарий для защиты

1. На первом экране подключите папку распакованной сборки Flowseal или выберите «Позже».
2. В каталоге найдите **Northbound** и откройте его карточку. Добавьте профиль в библиотеку.
3. В «Моих решениях» включите профиль, откройте предпросмотр и экспортируйте JSON. Включённый профиль участвует в подготовке только при подходящей стратегии. Демо-профили исключаются из плана изменений.
4. Выберите стратегию на главной. В настройках проверьте диагностику и включите поиск Steam при первом посещении страницы игр. Сохранённые настройки и профили восстанавливаются при следующем запуске.

## Возможности версии 0.1

| Раздел | Что доступно |
| --- | --- |
| Интерфейс | Обзор состояния подключения, боковая навигация, список и детали профиля в соседних панелях, анимация переходов. |
| Каталог | Поиск по названию и описанию, фильтры, детали, добавление и удаление. Встроенные профили вымышлены и помечены «Демо». |
| Мои решения | Включение и отключение, удаление, импорт и экспорт одного JSON-профиля. Импорт ограничен 512 КБ и проверяет поля, формат адресов и дубликаты. |
| Интеграция | Проверка структуры папки, поиск `general*.bat`, выбор стратегии, чтение версии и диагностика компонентов. |
| Предпросмотр | Сравнение со списками сборки, объединение уникальных записей, предупреждения о конфликтующих записях и несовместимости. |
| Игры | Чтение локальных манифестов из основной и дополнительных библиотек Steam. |

Библиотека, настройки и журнал ошибок хранятся в `%LOCALAPPDATA%\Zapretiks`. Статус процесса остаётся неизвестным. Запуск, остановка и управление службами запланированы. Применение файлов и откат отложены до реализации резервного копирования. Онлайн-каталог и сопоставление профилей с играми описаны в [дорожной карте](ROADMAP.md).

## Проверки

```powershell
dotnet run --project Zapretiks.Tests -c Release
```

Набор проверок запускается без внешнего тестового пакета и возвращает ненулевой код при ошибке. Для создания примера JSON экспортируйте один из демонстрационных профилей в приложении.

Оригинальная сборка принадлежит Flowseal, исходный zapret разработан bol-van. Компоненты Flowseal и WinDivert распространяются отдельно на условиях их лицензий.
